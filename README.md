# Darya Zhadenko Frontend developer CV

Repository for the web page containing my CV.
You can view the CV at [the following link](https://dasha13zh.github.io/cv/).

## Stack

React + TypeScript + Vite

## Scripts:

To run locally:

```shell
npm run dev
```

To deploy changes:

```shell
npm run deploy
```

To preview the app:

```shell
npm run preview
```

The project includes icons used in the Stack section.

To preview the app:

